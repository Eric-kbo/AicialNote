# AicialNote

**Ваши аккаунты и заметки — в вашем собственном облачном хранилище.**

Менеджер с открытым исходным кодом для логинов, паролей, 2FA, резервных адресов почты и прокси.<br>
Без базы данных на сервере: данные хранятся в вашем Google Drive или OneDrive в виде обычных файлов.

## Зачем AicialNote

Большинство менеджеров паролей хранят ваше хранилище на своих серверах, в формате, который может прочитать только их
приложение. AicialNote устроен наоборот:

- **Файлы принадлежат вам.** Всё хранится в **вашем** Google Drive или OneDrive (или в локальной папке) в формате JSON,
  а рядом создаются копии в Markdown и CSV. Если AicialNote завтра исчезнет, вы по-прежнему сможете открыть свои данные
  в любом текстовом редакторе или в Excel.
- **Сервер никогда не видит ваших данных.** Браузер обращается к Google и Microsoft напрямую. Небольшой сервер на Go
  только завершает вход через OAuth и ничего не хранит.
- **Данные трудно потерять.** При каждой перезаписи сохраняется предыдущая версия, всё удалённое попадает в папку
  корзины, а при конфликте синхронизации сохраняются обе версии.

> [!WARNING]
> **AicialNote находится в стадии альфа-версии.** Демо-режим и локальная папка хорошо протестированы; синхронизация с
> Google Drive и OneDrive появилась недавно. Пока она не докажет свою надёжность в вашем случае, держите резервную копию
> (**Export data… → Full backup (JSON)**) и прочитайте раздел [Модель безопасности](#модель-безопасности), прежде чем
> хранить настоящие пароли.

## Возможности

- **Один список для всех личностей.** Каждый ID содержит карточки: Google, Apple ID, Microsoft, OpenAI, Claude,
  почта, сайт, API-ключ, прокси, сервер, Wi-Fi, банковская карта, адрес доставки, профиль, удостоверение личности или
  собственный тип. Фильтрация по статусу, тегу, типу карточки или скорому истечению срока.
- **Копирование в один клик.** Нажмите на любое значение, чтобы скопировать его. Поля 2FA показывают текущий код TOTP.
- **Умная вставка.** Вставьте `Email: a@gmail.com Password: …`, `email----password----recovery----2FA`,
  `ip:port:user:pass` или сотню таких строк, и AicialNote заполнит поля.
- **Блокноты.** Блокноты, разделы и страницы с редактором форматированного текста в стиле OneNote. Аккаунты можно
  раскладывать по разделам рядом с заметками.
- **Локально в первую очередь.** Чтение и запись происходят мгновенно и работают без сети. Синхронизация идёт в фоне.
- **Импорт и экспорт.** Полные резервные копии в JSON, экспорт в CSV и Markdown, восстановление из любой копии в `trash/`.
- **Управление с клавиатуры.** `Ctrl/⌘ K`, `/`, `J`/`K`, `N`, `Ctrl/⌘ V`. Светлая и тёмная темы, интерфейс на китайском
  и английском языках.

## Начало работы

### Использовать готовую версию

Перейдите на **[aicialnotes.com](https://aicialnotes.com)**, войдите через Google или Microsoft — и всё готово. Ничего
устанавливать не нужно. Сайт получает доступ только к тем файлам, которые создаёт сам:

| Провайдер       | Разрешение                  | К чему у AicialNote есть доступ                      |
| --------------- | --------------------------- | ---------------------------------------------------- |
| Google Drive    | `drive.file`                | Только к файлам, созданным AicialNote                |
| OneDrive        | `Files.ReadWrite.AppFolder` | Только к папке `Apps/AicialNote`                     |
| Локальная папка | Доступ браузера к файлам    | Только к выбранной вами папке (браузеры на Chromium) |

### Развернуть у себя

AicialNote поставляется как один исполняемый файл (или один контейнер) со встроенным веб-приложением. Зарегистрируйте
OAuth-приложение в Google и/или Microsoft, задайте четыре переменные окружения и запустите. Подробнее:
[docs/self-hosting.md](../../docs/self-hosting.md).

## Как это устроено

```text
┌────────────────────┐   OAuth only    ┌─────────────────────────┐
│  Browser (React)   │ ───────────────▶│ AicialNote server (Go)  │  no database,
│  IndexedDB cache   │                 │ token broker + SPA      │  never sees data
└─────────┬──────────┘                 └─────────────────────────┘
          │ files (JSON / MD / CSV), directly
          ▼
   Google Drive  ·  OneDrive  ·  local folder
```

Что вы найдёте в своём хранилище:

```text
AicialNote/
├── vault.json                 settings
├── items/<id>.json            the data, one file per ID
├── notes/<id>.json            notebooks, sections and pages
├── history/<id>/…             previous versions, kept on every change
├── trash/                     deleted items
├── readable/                  generated Markdown and CSV copies (open in any editor or Excel)
└── index.json                 generated index
```

Формат файлов в хранилище — публичный версионируемый контракт: [docs/data-format.md](../../docs/data-format.md).

## Модель безопасности

- **Пока AicialNote не шифрует ваши данные.** Файлы в хранилище и локальный кеш браузера (IndexedDB) хранятся в
  открытом виде. Они защищены ровно настолько, насколько защищены ваш облачный аккаунт и ваше устройство, поэтому
  включите двухэтапную проверку для облачного аккаунта. Необязательное сквозное шифрование есть в планах.
- **Сервер никогда не видит ваших данных.** Он только завершает вход через OAuth. Refresh-токен хранится в cookie с
  флагом HttpOnly, зашифрованном AES-GCM; у сервера нет базы данных, и он ничего не хранит.
- **Минимальные разрешения.** См. таблицу в разделе [Начало работы](#использовать-готовую-версию).
- **Строгая CSP.** `script-src 'self'`, а в `connect-src` перечислены только хосты Google Drive и OneDrive.

Нашли уязвимость? Пожалуйста, сообщите о ней конфиденциально, как описано в [SECURITY.md](../../SECURITY.md).

## Разработка

Требования: Node 22+, pnpm 10+, Go 1.26+.

```sh
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 pnpm install
pnpm dev            # веб-приложение на http://localhost:5173
pnpm dev:server     # OAuth-брокер на :8080 (нужен server/.env, см. server/.env.example)
```

В режиме разработки на стартовой странице есть кнопка **Open demo data**, которая работает полностью в памяти, так что
для работы над интерфейсом учётные данные OAuth не нужны.

```sh
pnpm test           # модульные тесты (TypeScript + Go)
pnpm typecheck
pnpm lint
pnpm smoke          # сквозные проверки в Chrome на `pnpm dev`
pnpm screenshots    # скриншоты интерфейса: светлая/тёмная тема, zh/en
pnpm build          # один исполняемый файл со встроенным веб-приложением: server/bin/aicialnote
```

| Путь               | Содержимое                                                                   |
| ------------------ | ---------------------------------------------------------------------------- |
| `packages/core`    | модель данных, умная вставка, TOTP, читаемые экспорты, операции с хранилищем |
| `packages/storage` | адаптеры хранилищ: Google Drive, OneDrive, локальная папка, память           |
| `web`              | приложение на React: локальный кеш, движок синхронизации, интерфейс          |
| `server`           | Go: OAuth-брокер и сервер статических файлов                                 |
| `docs`             | формат данных, принципы дизайна, самостоятельное развёртывание               |

Состояние проекта, проектные решения и заметки для участников: [docs/status.md](../../docs/status.md),
[docs/decisions.md](../../docs/decisions.md), [CLAUDE.md](../../CLAUDE.md).
